## 运行要求

- 《以撒的结合：忏悔+》版本 `1.9.7.15`
- 本 Mod 仅在游戏版本 `1.9.7.15` 上进行测试；其他版本尚未验证。
- 只使用标准 Lua Mod API，不需要 REPENTOGON
- [Mod Config Menu Impure](https://steamcommunity.com/sharedfiles/filedetails/?id=3701683951) 为可选依赖

<a id="tainted-lost"></a>
## 里游魂

- 每次新开局初始携带木十字架（饰品 ID 121）；继续已有游戏不会重复给予。

<a id="tainted-blue-baby"></a>
## 里蓝人

- 恶魔交易采用小蓝人的等价魂心价格：原价 1/2 个心之容器的道具分别花费 1/2 颗魂心，不再全部花费 3 颗魂心。多人游戏中，调整后的付款只对实际购买的里蓝人生效。
- 大便队列满容量时，小型与大型大便拾取物仍保留碰撞，但不会被拾取，会留在地上以便之后使用；未满容量时保持原版拾取行为。

<a id="tainted-eden"></a>
## 里伊甸与 Roll 全身道具

- Roll 全身道具后，会保留每位玩家 Roll 前的血量构成，包括心之容器、已填充红心、魂心/黑心、骨心、腐心、碎心、永恒之心和金心。
- 独立的修复会保留虚空与黑符文已经给予的永久属性，并按玩家分别记录；旧被动道具本身提供的属性仍会随 Roll 全身道具正常改变。
- 覆盖里伊甸惩罚伤害、D4、D100、D 无限对应骰面、虚空或节拍器间接触发的 D4/D100、编号丢失、1 点与 6 点骰子房、“命运之轮？”以及同类被动道具整体替换。
- 献血机、恶魔乞丐、赌命乞丐、IV 袋、刺房门和献祭房尖刺等自愿伤害保持原版行为。
- 独立的错误技概率滑块控制每次 Roll 全身道具时，隐藏房池是否包含错误技：`0%` 总是排除，`50%` 平均一半的 Roll 会包含，`100%` 保持原版行为。正常底座拾取及 Roll 前已经持有错误技的情况不受限制。被拒绝的错误技会在进入物品栏之前替换为被动或跟班道具，因此不会生成额外错误道具、与主动槽冲突或改变 Roll 后的道具数量。
- 小以扫首次使用时生成的道具会恰好一次登记到原版套装进度；之后切换身体不会重复触发首次拾取效果。

<a id="bethany"></a>
## 伯大尼

- 获得魂心时提供双倍魂心充能：一整颗魂心提供 4 点，半颗提供 2 点；地面拾取和道具直接给予都有效。
- 魂心充能会吸收降低恶魔房/天使房概率的惩罚性伤害，同时保护红心和交易房概率；半颗红心伤害消耗 2 点，整颗消耗 4 点，只要有正数充能就能吸收一次符合条件的伤害。
- 恶魔乞丐、赌命乞丐、献血、献祭房尖刺和进出刺房等安全伤害仍会正常扣除红心，并且绝不消耗魂心充能。
- 被吸收的惩罚性伤害仍会摧毁满分考卷并影响其进度；只保护红心和交易房概率。
- 格罗激活期间，美德书魂火继续围绕其所属玩家，不会把环绕中心转移到格罗；魂火与格罗的属性、数量和持续时间保持不变。
- “护盾视听效果”提供旧版半透明“魂心薄幕”、蓝色能量片“粒子墙”和厚实的“磨砂魂盾”，另有五种“先明显增亮再减弱为余辉”的受击效果和三组原创魂心护盾音效。每组音效都会连续混合自制的薄、中、厚三段录音；视觉与声音的大部分变化集中在 0～30 充能，随后平缓过渡至 99。MCM 可在不受伤时分别预览待机、受击及 4/30/99 充能音效。格挡时伯大尼保持动作且不播放受伤语音；关闭此选项时护罩会伴随所选消失声渐隐。

<a id="familiar-capacity"></a>
## 跟班上限修复

- 保留原版 64 个真实跟班的硬上限，不需要 REPENTOGON。
- 蓝苍蝇和蓝蜘蛛只会把真实跟班总数填到 60 的软上限；溢出数量按玩家和类型分别保存，有空位时每 3 帧最多补回 2 个。
- 永久跟班、任务跟班、魂火、骨刺及其他重要跟班绝不会被主动存入缓冲池。到达硬上限边缘时，会收回一只能够确认归属的蓝苍蝇或蓝蜘蛛，为重要跟班保留位置。
- 溢出动画会合并并限频。继续游戏会保留缓冲数量；关闭该功能只暂停处理而不会丢失数量；新开局会清零。

<a id="small-player-pickup-range"></a>
## 小体型拾取范围修复

- 战斗结束后，冥王星等缩小效果仍保持小体型外观，但角色的物理半径恢复正常拾取与接触范围；存在敌人的房间仍保留小体型战斗碰撞，且不会修改任何掉落物的体积。

<a id="clog-ground-damage"></a>
## 拦路屎水迹伤害修复

- 拦路屎（实体 914.0.0）可以受到玩家水迹伤害，包括免费柠檬水；伤害、范围和触发频率沿用当前水迹的数值，其他敌人不受影响。

<a id="held-item-protection"></a>
## 拾取动画修复

- 在收藏品拾取动画期间使用R键或遗忘药，会先完成拾取，再重置本局或当前层，避免道具尚未进入物品栏就随重置消失。联机时会分别完成每位玩家尚未结算的拾取。

<a id="kids-drawing-form-fix"></a>
## 儿童涂鸦套装修复

- 持有妈妈的盒子时，儿童涂鸦会为嗝屁猫套装额外计 1 件：普通版本合计 2 件，金色版本合计 3 件。因此金色儿童涂鸦与妈妈的盒子可以直接触发嗝屁猫变身。

<a id="ocular-rift-sound-fix"></a>
## 邪眼裂口音效修复

- 持有邪眼裂口但没有发射泪弹时，手指！等持续触发泪弹特效的道具不会再异常播放邪眼裂口的发射音效；实际发射泪弹及生成裂口的音效保持原版行为。

<a id="mod-config-menu"></a>
## [Mod Config Menu Impure](https://steamcommunity.com/sharedfiles/filedetails/?id=3701683951) / 配置菜单

第一个选项用于选择默认的 English 或简体中文。菜单每次只显示所选语言，语言选择与游戏功能设置分别保存。

十七项游戏功能可以独立配置：

1. 跟班上限修复
2. 小体型拾取范围修复
3. 拦路屎水迹伤害修复
4. 拾取动画修复
5. 儿童涂鸦套装修复
6. 邪眼裂口音效修复
7. 初始木十字架
8. 小蓝人交易价格
9. 大便队列溢出修复
10. Roll 全身道具后保留血量
11. Roll 全身道具后保留吸收属性
12. 小以扫拾取效果
13. Roll 全身道具时错误技概率
14. 双倍魂心充能
15. 魂心充能护盾
16. 护盾视听效果
17. 格罗魂火环绕修复

选项分别归入简短的 `通用`、`里游魂`、`里蓝人`、`里伊甸` 和 `伯大尼` 顶栏。集成同时支持 Mod Config Menu Impure 的全局
`MCM` 接口，以及提供 `ModConfigMenu` 的旧版或本地化版本。未安装 MCM 时，已保存设置或默认设置仍会正常工作。

<a id="installation"></a>
## 安装

将完整的 `character-enhance` 文件夹复制到游戏的 `mods` 目录，然后在游戏内 Mod 菜单中启用。

Steam Deck/Linux：

```text
/home/deck/.local/share/Steam/steamapps/common/The Binding of Isaac Rebirth/mods/character-enhance
```

Windows：

```text
C:\Program Files (x86)\Steam\steamapps\common\The Binding of Isaac Rebirth\mods\character-enhance
```

多人游戏中，每位符合条件的角色及其跟班缓冲会分别处理。
